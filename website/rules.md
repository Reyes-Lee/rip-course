## 兩條硬規定 { #hard-rules }

程式和模型的限制都從這兩條來。下表一欄一條規定：它的意思、因此不能改的東西、你們要交什麼來證明。

| | 規定一：Nano 的 .ino 不能改 | 規定二：只能用 RL 訓練 |
| --- | --- | --- |
| 意思 | 甩上、平衡的動作全部由 Nano 上的網路計算。筆電只負責供電和記錄分數；在筆電上算動作的控制器（例如 `08_test_policy`）不算 | 蒸餾前的模型要是你們自己用強化學習訓練的。最後燒進去的網路就是它，或是用它的動作當標籤蒸餾出來的（蒸餾後的模型）。不能用 LQR、PID、手動示範當標籤 |
| 因此不能改 | 課程版 `firmware/RLControl/RLControl.ino`，以及它固定的韌體接口：網路結構 24 → 16 → 16 → 1（隱藏層大小 H 固定 16）、觀測（最近 4 幀）、50 Hz、速度上限 3.5 rad/s、加速度上限 150 rad/s²、動作平滑 4 拍，見 [Step 4「`RLControl.ino` 固定了什麼」](steps/step4-deploy.md#fixed) | 標籤的來源：只能是蒸餾前的模型（你們用 RL 訓練的） |
| 要交 | `policy_weights_student.h`（只有權重） | 蒸餾前的模型（`teacher.zip` 或 `teacher_act.py`）和它的 `config.json`，格式見[下面](#teacher) |

!!! warning "硬體也不能改"

    Vref、微步、接線、編碼器、配重都照交付狀態，不加感測器或機構輔助。硬體有問題（零件壞了、讀值怪、馬達失步），在 Discord 開 ticket 找助教，不要自己動手修改。損壞和更換的規定見[器材使用規定](#equipment)。

### 蒸餾前模型的格式 { #teacher }

RL 演算法和函式庫不限，但交出來的蒸餾前模型必須能在課程 repo 的 Python 環境（`policy/`，有 PyTorch、numpy、Stable-Baselines3）裡直接執行：

- 用 Stable-Baselines3（照課程流程就是）：交 `.zip`。
- 用其他方法：另外交一支只用上面這些套件的 `teacher_act.py`，提供 `act(obs) -> action`。`obs` 是 24 個數（觀測的格式見 [Step 1](steps/step1-train.md#obs)），`action` 在 −1 到 1 之間。並附上訓練這個模型的程式。

## 其他都可以改 { #scope }

網站的五個步驟是**建議做法**，你們不一定要用課程工具或作者的程式。只要守住兩條硬規定，下面這些都由你們決定：

- reward 的權重與公式
- RL 演算法與函式庫（不一定要 SAC 或 SB3）
- 模擬環境與 domain randomization（包括延遲），訓練步數、SEED
- 實機微調：回合數、段數、次數都不限；`LowLevelServer`、`finetune_async.py` 和各個訓練腳本都可以改
- 蒸餾方法（蒸餾後模型的隱藏層大小固定 16，見上表）
- 直接用 RL 訓練 24 → 16 → 16 → 1 的小網路、不蒸餾（這時 `teacher.zip` 交的就是它本身）
- 延遲階梯和甩上到平衡計時用不同的策略

和延遲有關、工具裡就能改的設定，見[專題任務的「可以調的地方」](advanced.md#knobs)。

## 器材使用規定 { #equipment }

1. **領取時現場測試**：Nano 已經燒好快速檢查韌體 `PickupCheck`。現場接上 USB 與 12 V，照提示轉一下擺錘，約 1 分鐘測完編碼器與馬達，並清點零件、拍照。有問題當場更換。測試完雙方在點交單上簽名，之後以點交單為準。完整的編碼器與失步測試回去照[硬體與上電測試](prepare/hardware.md)自己做（方向標定助教發放前已經做過）。
2. **之後的損壞**：正常使用下的損壞，每組每一種零件可以免費更換一次。需要更換時在 Discord 開 ticket 找助教，換新時請交回壞掉的零件，交不出來就視為遺失。
3. **不算正常使用的情況**：違反網站上明確寫出的注意事項（例如 12 V 接著時插拔馬達線、轉 TMC2209 的 Vref 可變電阻、12 V 接到 Nano、AS5600 的 DIR 腳接 5V）、摔落、自行改裝硬體。這些損壞不免費更換。是否屬於正常使用，由助教和老師判斷，你們可以說明情況。
4. **遺失**不免費補。
5. **繳回**：繳回日期另外公告。損壞或遺失、而且不屬於正常使用的零件，全組依價格表照價賠償。價格表另外公告。
6. 課程發放 12 V 電源供應器與軸承；USB-C 傳輸線（要能傳資料）和 10 元硬幣請自備。杜邦線、膠帶、螺絲等消耗品不在此規則內。
